Все страницы ссылаются на app.php
К нему подключается autoload, который загружает config, и route
Глобальные переменные хранятся в config.php, константа AJAX_REQUEST_URL генерируются в route.php
route подключает файлы, которые зависят от URL_PATH, то есть alias в дереве материалов,
скрипты и стили (уникальные для страницы и общие - main.css.php и main.js.php),
панель навигации (prepare_navbar, navbar.blade).

в папке php_functions для каждой страницы должен быть файл prepare_<alias>.php //в нём получаются данные из бд для вывода на странице
в папке blades для каждой страницы должен быть файл <alias>.blade.php //вывод данных на странице
в папке assets для каждой страницы должны быть файлы скриптов и стилей вида <alias>.js.php и <alias>.css.php
в папке ajax для каждой страницы должен быть файл для ajax запросов  вида ajax_<alias>_functions.php
