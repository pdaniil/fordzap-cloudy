АРХИТЕКТУРА МОДУЛЯ ПАРСЕРА
===========================

1. ОБЩАЯ СТРУКТУРА
------------------
Модуль построен по принципу фасада - один основной класс PageParser,
который использует несколько специализированных классов для каждой задачи.

Плюсы такого подхода:
- Каждый класс отвечает только за свою функцию
- Легко тестировать отдельные компоненты
- Просто добавлять новые возможности
- Код читаемый и поддерживаемый

2. ДИАГРАММА ВЗАИМОДЕЙСТВИЯ
----------------------------
PageParser (фасад)
    ├── CacheManager - работа с кэшем
    ├── BlacklistManager - черный список доменов
    ├── HttpFetcher - загрузка страниц
    ├── HtmlAnalyzer - анализ HTML
    ├── HtmlCleaner - очистка HTML
    ├── ErrorHandler - обработка ошибок
    └── CloudflareHandler - работа с Cloudflare

3. ПОТОК ДАННЫХ
---------------
1. PageParser::parse($url) - входная точка
2. Проверка черного списка
3. Проверка кэша
4. HttpFetcher пытается загрузить страницу
5. HtmlAnalyzer анализирует результат
6. При необходимости CloudflareHandler делает вторую попытку
7. ErrorHandler обрабатывает ошибки и добавляет в черный список
8. HtmlCleaner очищает HTML от мусора
9. Результат сохраняется в кэш и возвращается

4. ОПИСАНИЕ КЛАССОВ
-------------------

4.1. PageParser (фасад)
     Главный класс, с которым работают внешние скрипты.
     Координирует работу всех остальных классов.
     Содержит основную логику парсинга.

4.2. CacheManager (уже есть)
     Отвечает за кэширование результатов.
     Сохраняет страницы в файлы, проверяет время жизни.
     Методы: get(), set(), clear()

4.3. BlacklistManager (уже есть)
     Управляет черным списком доменов.
     Хранит список в JSON файле.
     Методы: isBlacklisted(), add(), remove(), getAll()

4.4. HttpFetcher
     Загружает страницы через CURL.
     Работает с user-agent, таймаутами, редиректами.
     Возвращает HTML или false при ошибке.

4.5. HtmlAnalyzer
     Анализирует HTML без его изменения.
     Определяет JS-фреймворки, SPA, блокировки.
     Проверяет кодировку.

4.6. HtmlCleaner
     Очищает HTML от мусора.
     Удаляет скрипты, стили, навигацию.
     Извлекает заголовки, мета-теги, текст.

4.7. ErrorHandler
     Обрабатывает ошибки загрузки.
     Классифицирует ошибки (таймауты, SSL, HTTP).
     Добавляет проблемные домены в черный список.

4.8. CloudflareHandler
     Работа с Cloudflare Browser Rendering.
     Загружает сложные JS-сайты.
     Пробует Markdown и HTML варианты.

5. НАСТРОЙКИ (config.json)
-------------------------
{
    "parser": {
        "timeout": 10,              // Таймаут загрузки (сек)
        "min_length": 100,          // Минимальная длина текста
        "max_length": 100000,        // Максимальная длина текста
        "use_cache": true,           // Использовать кэш
        "cache_ttl": 86400,          // Время жизни кэша (24 часа)
        "clean_html": true,          // Очищать HTML
        "remove_scripts": true,      // Удалять скрипты
        "remove_styles": true,       // Удалять стили
        "remove_navigation": true,    // Удалять навигацию
        "extract_title": true,        // Извлекать заголовок
        "extract_description": true,  // Извлекать описание
        "extract_keywords": true      // Извлекать ключевые слова
    }
}

6. ЛОГИРОВАНИЕ
--------------
Все классы пишут логи через writeLog().
Формат: [timestamp] [уровень] [компонент] сообщение
Уровни: info, error, warning, debug

7. РАСШИРЕНИЕ
-------------
Чтобы добавить новый источник данных (например, другой API):
1. Создать новый класс-обработчик
2. Добавить его использование в PageParser

Чтобы добавить новый способ анализа:
1. Добавить метод в HtmlAnalyzer
2. Использовать в PageParser

8. ТЕСТИРОВАНИЕ
----------------
Каждый класс можно тестировать отдельно:
php test_httpfetcher.php
php test_htmlanalyzer.php
php test_cloudflare.php
